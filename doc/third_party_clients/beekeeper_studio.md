   # Beekeeper Studio

   **Note:** This is a placeholder opened alongside issue #600, which proposes
   adding a "Database clients" / GUI tools section to the Greengage DB docs.
   This file's location and format are not final. It's here to make the
   proposal concrete while we wait to hear from maintainers on where this
   content should actually live.

   Beekeeper Studio (https://www.beekeeperstudio.io/) is a free, open source
   SQL editor and database manager with native Greengage support (added in
   v5.7, works against both v6 and v7).

   See https://www.beekeeperstudio.io/db/greengage-client/ for more.
